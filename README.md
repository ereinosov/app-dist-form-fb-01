## Organización del repositorio

Cada integrante tiene sus archivos en su propio directorio: sus documentos fuente en LaTeX (`.tex`), su bibliografía y su PDF compilado. Cada carpeta incluye además un `README.md` con las instrucciones para compilar ese trabajo (compilador, archivo principal, orden de comandos y dependencias).

```
.
├── coronel/
├── garcia/
├── piguave/
└── reinoso/
```

Para compilar el trabajo de un integrante, entra en su carpeta y sigue el `README.md` que hay dentro.
